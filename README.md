# Raitha Bharosa Hub (ರೈತ ಭರೋಸಾ ಹಬ್‌)

Raitha Bharosa Hub is a smart agricultural decision-support mobile application designed for smallholder farmers. It translates simulated agricultural data into actionable insights, helping farmers with sowing, fertilization, and environmental monitoring.

## Features

- **Bilingual Support**: Full support for English and Kannada.
- **Smart Dashboard**: Real-time overview of soil conditions and sowing indices.
- **Input Center**: Easily record soil moisture and NPK levels.
- **Krishi Calendar**: Get unique daily advisories based on weather forecasts.
- **History Tracking**: Keep track of your farm's health over time.
- **Data Persistence**: Your profile and farm data are securely stored locally.

## Technologies Used

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Modern UI toolkit for building native Android interfaces.
- **Room**: Persistence library for local database management.
- **DataStore**: Modern data storage solution for user preferences.
- **Retrofit**: Type-safe HTTP client for weather API integration.

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio (Iguana or later).
3. Build and run the app on an emulator or a physical device.

## Localization

The app is fully localized in English and Kannada. You can toggle between languages directly from the dashboard top bar.
